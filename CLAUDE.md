# Intro-Java-Lessons

Java learning exercises. Each subdirectory is a self-contained lesson or project.

## Convention
- No CI, no build tooling required unless the exercise includes Maven/Spring Boot
- When explaining Java concepts, relate to TypeScript/JS equivalents where helpful (Jay knows TS deeply)
- Code style: standard Java conventions, no over-engineering for learning exercises
- Comments are fine here (learning context) — but explain the WHY, not just the WHAT
